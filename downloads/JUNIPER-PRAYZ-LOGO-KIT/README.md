# JUNIPER & PRAYZ logo and merch kit

- `png/`: 2400 px presentation files plus 3000 px transparent files
- `svg/`: editable vector masters
- `affinity-ready/`: the same editable vector masters, ready to open in Affinity Designer
- `fonts/`: Instrument Sans regular/italic variable fonts and licence
- `merch-concepts/`: six 1600 × 1200 product concept sheets

## Affinity Designer

Install Instrument Sans, open an SVG from `affinity-ready`, then use **File → Save As** to create the native `.afdesign` working file. Convert text to curves only in a duplicate made for production.

Do not rename an SVG to `.afdesign`; the native format is proprietary and must be saved by Affinity itself.

## Production warning

The artwork is design-ready but not printer-certified. Confirm exact physical size, line weight, ink/thread count, garment color and bleed with the chosen supplier after samples are selected.
