# Affinity Designer handoff

Affinity Designer opens the included editable SVG files directly.

1. Install Instrument Serif and Instrument Sans from `downloads/JUNIPER-PRAYZ-IDENTITY-V2/fonts`.
2. Open one SVG from `downloads/JUNIPER-PRAYZ-IDENTITY-V2/svg-editable`.
3. The supplied SVGs already contain outlined paths, so the artwork does not depend on installed fonts. Use the fonts only when adding new copy.
4. Choose **File → Save As** and save the native `.afdesign` working file.
5. Duplicate the document before adapting colours or artwork for a specific printer.

Native `.afdesign` is a proprietary Affinity format and cannot be generated reliably without Affinity Designer itself. The supplied SVGs are the editable interchange masters, not renamed or simulated `.afdesign` files.
