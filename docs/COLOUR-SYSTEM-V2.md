# Colour system — quick reference

| Role | Name | Hex |
| --- | --- | --- |
| Deep background | Night | `#151219` |
| Brand atmosphere | Aubergine | `#24172E` |
| Light background | Porcelain | `#F7F1EA` |
| Voice one / action | Coral | `#F16A5B` |
| Voice two / counterpoint | Periwinkle | `#A9B6F4` |
| Secondary text / rules | Mist | `#DAD5DC` |

Core pairings:

- Night + Porcelain
- Aubergine + Porcelain
- Coral + Night
- Periwinkle + Night
- Coral + Periwinkle for the two-voice symbol

The palette is intentionally nocturnal, editorial and relational. It must not drift back toward the PRAYZVIBES olive, wheat, field-gold or vintage-road system.
