# Type and label system

## One family

Use **Instrument Sans Variable** everywhere. Regular, bold and italic are weights/styles of the same family, not additional identities.

- Display: 800–900, tight tracking, compact line height
- Body: 430–550, normal tracking
- Buttons: 800–900, uppercase
- Notes: 600–750

The font files and OFL license are in `/fonts`.

## One label grammar

Labels are short uppercase coordinates separated by a slash:

- `LIVE / CLOSE`
- `BUSKING DUO / BAVARIA`
- `PAVEMENT EDITION / DROP 01`
- `STREET / ROOM / GARDEN / STAGE`

Use one or two ideas only. Do not turn labels into sentences.

## Palette

- Ink `#15180F`
- Cream `#F4EBD8`
- Gold `#E7C96F`
- Moss `#6D7949`

Avoid adding campaign colors without removing one of these four.
